# Kestrel Launcher

A clean, fast launcher for Minecraft: Java Edition, starting with 1.8.9.

**[Download for Windows](https://github.com/viaturtles/kestrelclient/releases/latest)** · **[Website](https://viaturtles.github.io/kestrelclient/)** · **[Discord](https://discord.gg/8pVEuMc6NZ)**

- Separate setups for each version, with mods, resource packs and shaders from Modrinth
- OptiFine set up with OptiFine's own installer
- Launch Control: every launch step, a live console, memory and CPU, and plain-English crash help
- Jump back into worlds and servers in one click
- Discord status, automatic updates, and your settings and packs brought over from .minecraft

Windows may say "Windows protected your PC" the first time, because the installer isn't code-signed yet. Choose **More info → Run anyway**.
