# Kestrel website

Plain HTML and CSS, no build step. Published to GitHub Pages by `.github/workflows/website.yml`.

- Preview locally: `node website/serve.cjs`, then open http://localhost:4173
- Download and Discord links live in one place: `site.js` (`KESTREL_LINKS`). Replace `OWNER/REPO` and the Discord invite.
- Images in `assets/` are made from `design/kestrel-art/` (hero = Windhover, download card = First Light).
- `assets/launcher.webp` is a screenshot of the launcher Home. Replace it when the Home redesign is final.
